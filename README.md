# 🛒 E-Commerce Sales Data Analytics & Power BI Dashboard

## 📊 Project Overview
This project is an **E-Commerce Sales Data Analytics project** that combines data analysis, SQL, Python, and Power BI to understand sales performance, customer behavior, product performance, profitability, payment methods, and order trends.

The project includes an interactive **Power BI dashboard** with two main views:
* **Sales Overview**
* **Customer Insights**

The goal is to transform raw e-commerce data into meaningful business insights that can support better decision-making.

---

## 🛠️ Tools & Technologies
* **Power BI** – Interactive dashboard and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations
* **SQL / PostgreSQL** – Data analysis and business queries
* **Python / Jupyter Notebook** – Data analysis and exploration
* **Excel** – Source data and data preparation

## 📈 Power BI Dashboard

### 1. Sales Overview
The Sales Overview page provides a high-level view of e-commerce performance.

### Key KPIs

* **Total Sales:** 3.07M
* **Total Orders:** 293
* **Total Profits:** 613.76K
* **Average Order Value:** 10.47K
* **Returned Rate:** 26.28%

### Visualizations

* Total Revenue by Month
* Order Status Distribution
* Total Sales by Product
* Total Sales by State
* Total Sales by Category
* Customer and City performance
* Interactive filters for Product, Category, Month, State, City, Order Status, and Payment Mode
